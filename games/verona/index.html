About this Project

Verona is not a game!

Verona is an MP3 player I developed in Godot to cope with the rising Spotify prices I would have to face when I graduated college. It is a feature complete MP3 player that supports playing music, pausing it, skipping it... Well, the normal functions of an MP3 player aren't very exciting.

But there is a suprise in this one!

Functions

It's an MP3 player, so you can play music on this from a pre-determined folder. The application remembers the last folder you chose when this is opened, so you should only need to do this once.

Additionally, because I prioritize sharing my music above all else, I implemented Discord Rich Presence into this project, so everyone can see what I'm currently listening to.

The Suprise

Keen eyes may have noticed already, but there is a "Geometry Dash" toggle. What does that mean?

Geometry Dash mode is an astonishingly feature-complete application of Geometry Dash mechanics to an MP3 player. When toggled, all of the songs loaded get a difficulty- and occasionally while listening to the music, the MP3 player will die and need to start over! Oh no! But the MP3 player gets better and tend to get further as it tries again and again.

The player also knows when the song is about to end, and plays the Level Complete SFX and potentially 1-3 coin SFX.
